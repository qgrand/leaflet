## What

**Admin access to whatever is enforcing this** (Windows Defender Application Control, AppLocker, or "Smart App Control" — a session has no way to tell which from the error alone) on this Windows machine.

## Exact steps

**Check Windows Security → App & browser control → Smart App Control** (if present, it's the most likely single culprit — it blocks unsigned/unrecognized executables by default and is common on new Windows 11 installs). If it's on, either turn it off or add an exception. If it's off/absent, check for an AppLocker or WDAC policy via `Get-AppLockerPolicy -Effective` (PowerShell, admin) or `Get-CIPolicy` (`ConfigCI` module) and add a path or publisher exception covering `**\target\debug\build\*\build-script-build` and `**\target\debug\build\*\*.exe` under any repo this machine builds Rust in — not just this one path, since `cargo clean` regenerates these binaries at fresh, unsigned paths every time and the exception needs to survive that.
